# THE LAW, AND WHY IT IS A QUOTING LAW.  `native_perl_e_stmt` lowers
# `perl -e CODE [ARGS…]` by writing `@ARGV = (<perl_quote(w)>, …);` and then the
# CODE VERBATIM — the target output is Perl, so only the arguments need
# translating. Everything therefore rests on one fact: a shell word written by
# `perl_quote` is a Perl double-quoted literal that Perl re-parses into exactly
# that word. That is cluster H's `perl_double_quote_roundtrip`, applied here at
# the fold's own use site, with the fold's LIST shape (order and count) included.
#
# TWO SIDES.  The emitting side is the fold's construction (`pq_char`/`pq_body`,
# `prelude`, `fold_dec`). The parsing side is Perl's, written independently:
# `pdq_until` (a double-quoted body parsed until the closing quote) and
# `perl_dec` (Perl's table, in which an UNDEFINED escape is the character
# itself). Neither side calls the other: a character the encoder forgets to
# escape becomes a parsing-side character, so the law goes red.
#
# ── the laws as landed (16 verified, 0 errors) ──────────────────────────
#   perl_literal_roundtrip      pdq_until(pq_body(s) ") == s, for every s
#   every_char_roundtrips       every single character, the seven escaped ones
#                               included
#   argv_prelude_law            the `@ARGV` prelude parses back to the words, in
#                               order, same count
#   decode_table_preserves_perl every escape the fold accepts, Perl reads the
#                               same way
#   refusal_is_conservative     every escape the fold REFUSES, Perl reads as the
#                               character — refusing costs a fold, never
#                               correctness
#   code_is_emitted_verbatim    the program text is the input, unchanged
#   pins: pin_first_argument_is_first, pin_unknown_escape_is_refused
#
# ── mutants (measured on these bytes, each restored by sha256) ──────────
#   M1 pq_char('$') drops the escape            15 verified, 1 error (assert)
#   M2 perl_unesc('n') decodes to 'N'            15 verified, 1 error (assert)
#   M3 prelude emits the words in reverse        15 verified, 1 error (assert)
#   M4 fold_dec('t') decodes to a space          15 verified, 1 error (postcond)
#   M5 fold_dec accepts an undefined escape      15 verified, 1 error (postcond)
#   No mutant was a spelling or compile error: each is a verification failure

# `native_perl_ne_stmt` is NOT a quoting fold — it emits computed OUTPUT — and
# its line loop has a defect this stage does not touch: it skips EVERY empty
# line when the input ends with a newline
# (`if line.is_empty() && input.ends_with('\n') { continue; }`), while Perl's
# `-ne 'print "P $_\n"'` prints the prefix once per line, blank lines included.
# For a literal producer (`printf '\n\n'`) the fold would emit one line too few.
# Its law is a line model, not this file's; the defect is left as recorded.
