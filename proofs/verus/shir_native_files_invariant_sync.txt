#
# THE INVARIANT.  `files: HashMap<String,String>` is a syntactic cache of what
# a literal `echo/printf > P` left in P; native_cat_file_pipeline substitutes
# `cat P` with it. A wrong entry is wrong OUTPUT, so this file proves soundness
# rather than a conservatism:
#   * files_sound_on_truncating_programs — for a program of literal TRUNCATING
#     writes, the map equals the disk at every path (induction, via
#     files_sound_step). cat_reads_current_disk is the use site.
#   * record_keeps_every_other_key / record_stores_the_payload /
#     refused_write_changes_nothing — files_monotone: one record touches one
#     key; a refusal touches nothing.
#   * append_is_refused_by_the_pass / append_appends_to_what_is_there /
#     truncate_then_append_diverges — d-A1: `> f` then `>> f` leaves the map
#     holding the first write while the disk holds both, so the fold's
#     `r.mode != "w"` refusal is REQUIRED.
#   * echo_bytes_are_what_bash_writes — the recorded content (single spaces, one
#     trailing newline) is bash's bytes, proved against a separator-join
#     recursion (lemma_add_assoc).
#   * second_redirect_is_refused — the one-spec, fd-1 gate.
#
# THE TWO SIDES ARE DIFFERENT FUNCTIONS.  The shell side (bash_write/bash_disk)
# models BOTH `>` and `>>`; the pass side (rec_write/rec_map) models only the
# insert the source performs, behind the gate. The theorem is the restriction,
# and the divergence on the complement is proved (d-A1), which is why the law
# cannot be green-by-agreement.
#
# A.2 (dispatch completeness) is the previous stage and is not re-proved here:
# proofs/verus/check_dispatch.py + shir_native_stmt_dispatch.txt (58 folds, both
# directions). Re-run in this stage: 0 failures.
#
# d-A2, RECORDED NOT FIXED: every way a path can change that the fold does not
# record (`echo $X > P` left as an exec, `cp`, `mv`, `sed -i`, a subshell write)
# leaves the entry stale, and a later `cat P` substitution would use the stale
# bytes. The map is a syntactic cache, not a filesystem model; the fold's own
# domain (literal truncating writes) is what this file proves sound.
#
# Out of model: the renderer; the parser; printf's byte side (cluster E's law,
# shir_native_echo.rs — this file carries the payload as opaque bytes and proves
# the MAP law); the filesystem beyond the path keys.
