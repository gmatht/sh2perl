# THE LAWS.  Each section has the pass's own construction (`pass_*`) against a
# semantic side written from what bash does (`bash_*`), never by calling the
# pass's predicate:
#   * let_value_law     — the emitted assignment expression evaluates to the
#                         value bash's `let ARITH` stores.  (The IR arithmetic
#                         `eval` is the target language's, out of model.)
#   * declare_case_law  — the case attributes the fold applies are bash's, for
#                         at most one of -l/-u.  declare_value_law carries it to
#                         the stored bytes.
#   * normalize_preserves_the_text / normalize_matches_bash_join — for a command
#                         that is not an assignment builtin the word list is
#                         unchanged; for `typeset` the join the fold performs is
#                         bash's assignment-builtin join (two recursions).
#   * trap_emits_one_effect_per_part — for a handler of modelled parts the
#                         emitted effect list has one entry per part;
#                         exit_contributes_no_effect is the runner's half.
#   * rm_status_law_existing_directory — `-r` is required and, with it, both
#                         statuses are 0; rm_recursive_flag_is_required shows
#                         the requirement is load-bearing for a directory.
#   * subshell_status_law_when_eval_succeeds — the redirect does not touch the
#                         status, so the fold's 0 is bash's 0 on success.
#   * perl_e_law        — the ARGV the emitted `@ARGV = (…)` sets is bash's.
#   * perl_ne_law       — the per-line bytes are bash's, for both the `chomp;`
#                         and the plain handler form.
#   * bash_script_law   — the fixed script's `Arg: $a` lines and its `$#` count.
#   * sort_keeps_every_line — `sort` is a permutation: no line added or dropped
#                         (ordering is PINNED on concrete inputs, not proved in
#                         general — see [counts]).
#

HONEST LIMITS, stated not claimed:
  * `sort`: the general law is the permutation/line-count one. Ordering is
    pinned on concrete inputs (3 1 2 -> 1 2 3 and -> 3 2 1), not proved for
    arbitrary lines; a general sortedness proof would need an insertion-sort
    invariant this stage did not take on.
  * `normalize_preserves_the_text` is stated as equality with the shell-side
    recursion for the non-assignment-builtin case; the textual claim for a
    SINGLE word is pinned, not proved symbolically over characters.
  * `let`/`declare`/`perl`/`bash_script` laws are laws about the MODEL the fold
    is transcription of (the IR it emits, the ARGV it sets, the lines it
    prints); the renderer is out of model throughout.
